## In thirty seconds

```sh
git clone https://github.com/hood/polso && cd polso
just install && just start                       # ~/Applications/Polso.app

echo '{"type":"value","slot":"left","value":42}' | nc -U ~/.config/polso/sock
echo '{"type":"alert","title":"Deploy failed"}'  | nc -U ~/.config/polso/sock
```
